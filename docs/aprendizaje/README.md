## Cómo estudiar estas notas

1. Lee la nota con el código abierto al lado (los enlaces llevan al archivo).
2. Haz los ejercicios: romper algo a propósito y leer el error enseña más que leer.
3. Si algo no queda claro, pregúntale a Claude citando la nota — y luego mejora la nota.
